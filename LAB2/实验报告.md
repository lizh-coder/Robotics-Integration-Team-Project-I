# LAB2 - ROS 安装与使用实验报告

## 1. 实验目标与复用情况

本实验通过两个无人机坐标系熟悉 ROS 1 的工作空间、package、node、topic、launch
以及 tf2。场景中世界坐标系为 `world`，两个机体坐标系为 `av1` 和 `av2`。

项目中已有 `LAB1/vnav-codes/lab2/two_drones_pkg`，目录结构和 MIT VNAV Lab 2
要求一致，因此本实验直接复用其模型、rviz 配置、launch 文件和代码骨架，并将副本
放在 `LAB2/lab2/two_drones_pkg` 中，避免修改之前实验的提交内容。补全内容为：

1. `frames_publisher_node.cpp`：50 Hz 发布 `world -> av1` 和 `world -> av2`；
2. `plots_publisher_node.cpp`：通过 `lookupTransform` 查询相对变换；
3. 显式补充 `geometry_msgs`、`tf2_geometry_msgs` 和 `visualization_msgs` 依赖。

## 2. 安装与工作空间

课程网页采用 ROS 1 Noetic 示例。推荐在 Ubuntu 20.04 中准备 ROS Noetic、catkin、
tf2、rviz 和编译工具。已经安装 ROS 的情况下不需要重复安装，只需确认：

```bash
source /opt/ros/noetic/setup.bash
roscore
```

另开终端创建或复用工作区：

```bash
mkdir -p ~/vnav_ws/src
cd ~/vnav_ws
catkin init
cp -a "/mnt/d/02_Academic/大三/机器人小组项目/LAB2/lab2/two_drones_pkg" src/
catkin build
source devel/setup.bash
```

每个新终端都要重新执行 `source /opt/ros/noetic/setup.bash` 和
`source ~/vnav_ws/devel/setup.bash`。运行前可用 `rospack find two_drones_pkg` 验证
包已经被 ROS 找到。

## 3. 交付物 1：节点、话题和 launch 文件

### 3.1 静态场景中的节点

忽略 ROS 系统自动产生的 `/rosout` 后，`static:=true` 时由 launch 文件启动：

| 节点 | 类型/作用 | 发布 | 订阅 |
|---|---|---|---|
| `/av1broadcaster` | `tf2_ros/static_transform_publisher` | `/tf_static` | 无 |
| `/av2broadcaster` | `tf2_ros/static_transform_publisher` | `/tf_static` | 无 |
| `/plots_publisher_node` | 发布无人机模型和轨迹 MarkerArray | `/visuals` | `/tf`、`/tf_static`（tf2 内部订阅） |
| `/rviz` | 可视化 | 无 | `/visuals`、`/tf`、`/tf_static` |

`/av1broadcaster` 发布 `world -> av1`，平移为 `(1, 0, 0)`；`/av2broadcaster`
发布 `world -> av2`，平移为 `(0, 0, 1)`。无人机网格模型由
`plots_publisher_node` 发布的 `/visuals` 中两个 `MESH_RESOURCE` Marker 触发 rviz
绘制，模型文件为 `mesh/quadrotor.dae`。

### 3.2 不使用 roslaunch 的启动方式

先在一个终端运行：

```bash
roscore
```

然后分别在其他终端加载工作区并运行：

```bash
rosrun tf2_ros static_transform_publisher 1 0 0 0 0 0 1 world av1
rosrun tf2_ros static_transform_publisher 0 0 1 0 0 0 1 world av2
rosrun two_drones_pkg plots_publisher_node
rosrun rviz rviz -d "$(rospack find two_drones_pkg)/config/default.rviz"
```

四条 `rosrun` 命令分别对应两个静态 tf 发布器、轨迹/模型发布器和 rviz。每个命令
应在单独终端执行，并在执行前 source ROS 与工作区环境。

### 3.3 去掉 `static:=true` 的变化

launch 文件中 `static` 的默认值是 `false`：

- `group if="$(arg static)"` 内的两个静态 tf 发布器不会启动；
- `frames_publisher_node` 上的 `unless="$(arg static)"` 生效，以 50 Hz 动态发布
  两个无人机坐标系；
- `plots_publisher_node` 和 rviz 仍会启动，但它们使用动态 tf，因此可以看到无人机
  按题目给定轨迹运动。

## 4. 交付物 2：发布坐标变换

设启动后的经过时间为 `t`。程序在 `frames_publisher_node.cpp` 中计算

```cpp
const double time = (ros::Time::now() - startup_time).toSec();
```

并发布：

```text
o_1^w = [cos(t), sin(t), 0]^T
o_2^w = [sin(t), 0, cos(2t)]^T
```

AV1 的姿态使用 `setRPY(0, 0, t)`。因为圆轨迹的切向量为
`[-sin(t), cos(t), 0]^T`，绕世界 z 轴 yaw=`t` 后，AV1 的 y 轴正好沿切线，z 轴
仍与世界 z 轴平行。AV2 使用单位四元数，姿态对本实验的相对位置曲线没有影响。

测试：

```bash
cd ~/vnav_ws
catkin build
source devel/setup.bash
roslaunch two_drones_pkg two_drones.launch
```

预期：AV1 在世界 x-y 平面作圆周运动，AV2 在世界 x-z 平面沿抛物线运动。

## 5. 交付物 3：查询相对变换

在 `plots_publisher_node.cpp` 中，给定参考坐标系 `ref_frame` 和目标坐标系
`dest_frame`，使用：

```cpp
transform = parent->tf_buffer.lookupTransform(
    ref_frame, dest_frame, ros::Time(0));
```

按照 tf2 的参数约定，该结果是“将 `dest_frame` 中的量表达到 `ref_frame` 中”的
最新可用变换。程序建立了三条轨迹：

- `world -> av1`：蓝色实线圆；
- `world -> av2`：红色实线抛物线；
- `av1 -> av2`：红色虚线闭合曲线。

将 rviz 的 Fixed Frame 改为 `av1` 后，AV1 看起来静止，世界坐标系绕 z 轴旋转，
AV2 相对 AV1 呈现倾斜平面上的椭圆。

## 6. 交付物 4：齐次变换与轨迹推导

### 6.1 AV2 在世界坐标系中的轨迹

令 `x=sin(t)`，则

```text
z = cos(2t) = 1 - 2 sin^2(t) = 1 - 2x^2,
y = 0.
```

因此 AV2 轨迹满足 `z=1-2x^2`、`y=0`，是世界 x-z 平面内的抛物线弧段。

### 6.2 齐次变换和 `o_2^1(t)`

记 `{}^wT_1` 为把 AV1 坐标表达成世界坐标的变换，`{}^wT_2` 同理。由于 AV1
的 yaw 为 t、AV2 姿态为单位旋转：

```text
{}^wT_1 = [ Rz(t)   o_1^w ]       {}^wT_2 = [ I   o_2^w ]
           [  0       1   ]                  [ 0     1  ]
```

其中

```text
Rz(t) = [ cos(t) -sin(t) 0 ]
        [ sin(t)  cos(t) 0 ]
        [   0       0    1 ]
```

相对变换为：

```text
{}^1T_2 = ({}^wT_1)^(-1) {}^wT_2,
o_2^1 = Rz(-t) (o_2^w-o_1^w).
```

代入 `o_1^w=[cos(t),sin(t),0]^T`、`o_2^w=[sin(t),0,cos(2t)]^T`：

```text
o_2^1(t) = [ sin(t)cos(t)-1 ]
            [    -sin^2(t)  ]
            [    cos(2t)    ]

          = [ -1 + 1/2 sin(2t) ]
            [ -1/2 + 1/2 cos(2t) ]
            [       cos(2t)      ].
```

### 6.3 轨迹所在平面

由上式的第二、第三分量：

```text
z_2^1 = cos(2t) = 2(-1/2+1/2 cos(2t))+1 = 2y_2^1+1.
```

所以轨迹位于平面

```text
Pi: z - 2y = 1,
```

其法向量可取 `n=[0,-2,1]^T`。

### 6.4 平面内的二维坐标系

按题目提示取平面内中心：

```text
p^1 = [-1, -1/2, 0]^T.
```

选取右手正交单位基：

```text
x_p = [1, 0, 0]^T,
y_p = [0, 1/sqrt(5), 2/sqrt(5)]^T,
z_p = [0,-2/sqrt(5), 1/sqrt(5)]^T.
```

其中 `z_p` 是平面法向量方向，且 `x_p × y_p = z_p`。于是

```text
{}^1R_p = [ 1       0          0       ]
           [ 0   1/sqrt(5)  -2/sqrt(5)]
           [ 0   2/sqrt(5)   1/sqrt(5)].
```

在 p 坐标系中：

```text
o_2^p = ({}^1R_p)^T(o_2^1-p)
      = [ 1/2 sin(2t) ]
        [ sqrt(5)/2 cos(2t) ]
        [       0       ].
```

第三分量为零，说明该坐标系确实位于轨迹平面内；轨迹关于 `x_p`、`y_p` 两轴
对称且以 p 为中心。

### 6.5 椭圆及半轴

由 `x_p=1/2 sin(2t)`、`y_p=sqrt(5)/2 cos(2t)` 得：

```text
(x_p/(1/2))^2 + (y_p/(sqrt(5)/2))^2 = 1.
```

因此 AV2 相对于 AV1 的轨迹是一个位于 `Pi` 内的椭圆，半长轴为
`sqrt(5)/2`，半短轴为 `1/2`。

## 7. 交付物 5：四元数线性映射

采用题目约定 `q=[q_1,q_2,q_3,q_4]^T`，其中前三项为虚部、最后一项为标量部。
四元数乘法满足：

```text
q_a ⊗ q_b = Omega_1(q_a)q_b = Omega_2(q_b)q_a.
```

### 7.1 `Omega_1(q)` 和 `Omega_2(q)` 正交

四元数范数满足乘法性：

```text
||q_a⊗q_b|| = ||q_a|| ||q_b||.
```

固定单位四元数 q，令 `L_q(x)=q⊗x`、`R_q(x)=x⊗q`。两者都保持任意 x 的欧氏
范数，因此对应矩阵 `Omega_1(q)`、`Omega_2(q)` 保持内积。由矩阵表示可得：

```text
Omega_1(q)^T Omega_1(q) = I_4,
Omega_2(q)^T Omega_2(q) = I_4.
```

正交矩阵还满足另一侧乘积也为单位阵。直观上，这是“单位四元数乘法是四维
欧氏空间中的长度保持旋转/反射型线性变换”的结果；这里连续性和行列式可进一步
确定为旋转型变换。

### 7.2 `Omega_i(q)^T q=e_4`

两矩阵的第四列都等于 q：

```text
Omega_1(q)e_4=q,    Omega_2(q)e_4=q,
e_4=[0,0,0,1]^T.
```

利用正交性：

```text
Omega_1(q)^Tq = Omega_1(q)^T Omega_1(q)e_4=e_4,
Omega_2(q)^Tq = Omega_2(q)^T Omega_2(q)e_4=e_4.
```

### 7.3 两种线性算子交换

对任意 `x,y,z`，由矩阵的含义：

```text
Omega_1(x)Omega_2(y)z = x⊗(z⊗y),
Omega_2(y)Omega_1(x)z = (x⊗z)⊗y.
```

四元数乘法满足结合律，所以两式相等，故

```text
Omega_1(x)Omega_2(y)=Omega_2(y)Omega_1(x).
```

再注意共轭四元数 `bar(y)=[-y_1,-y_2,-y_3,y_4]^T` 满足
`Omega_2(y)^T=Omega_2(bar(y))`。因此：

```text
Omega_1(x)Omega_2(y)^T z = x⊗(z⊗bar(y)),
Omega_2(y)^T Omega_1(x)z = (x⊗z)⊗bar(y).
```

再次使用结合律，得到：

```text
Omega_1(x)Omega_2(y)^T=Omega_2(y)^T Omega_1(x).
```

## 8. 可选交付物 6：内禀旋转与外禀旋转

采用列向量和主动旋转约定。设固定世界轴上的三个旋转矩阵按时间顺序为
`R_0,R_1,R_2`。外禀旋转每次绕固定轴左乘，因此最终姿态为：

```text
R_ext = R_2 R_1 R_0.
```

对附着在物体上的坐标轴，绕当前局部轴旋转等价于右乘相应旋转矩阵。若按反向
顺序使用 `R_2,R_1,R_0`（题目中的 intrinsic sequence），则：

```text
R = I R_2,
R = (I R_2) R_1,
R = ((I R_2) R_1) R_0 = R_2 R_1 R_0.
```

因此两种描述得到相同最终姿态。代入本题的 `R_0=R_x(90°)`、
`R_1=R_y(180°)`、`R_2=R_x(-30°)` 即可得到相同结果。
